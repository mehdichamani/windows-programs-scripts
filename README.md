# Windows Programs & Setup Scripts

مجموعه اسکریپت‌ها و ابزارهای خودکارسازی، نصب آفلاین و پیکربندی سیستم‌ها و ماشین‌های مجازی ویندوزی.

این مخزن برای نگهداری و همگام‌سازی اسکریپت‌های اجرایی ویندوز در کنار پوشه برنامه‌ها (`Programs`) طراحی شده است و به صورت مستقل بین سیستم‌های مختلف (خانه، محل کار، و ماشین‌های مجازی) همگام می‌شود.

---

## 📂 محتویات مخزن

| اسکریپت | توضیح عملکرد |
|---|---|
| **`install_fonts.bat` / `.ps1`** | نصب خودکار، گروهی و بدون وقفه تمامی فونت‌های موجود در پوشه والد `../Fonts` در رجیستری و پوشه Fonts ویندوز با دسترسی Administrator. |
| **`Install_Office365.bat` / `.ps1`** | اسکریپت نصب آفلاین و بی‌صدا/سفارشی آفیس ۳۶۵ (ODT) با دریافت خودکار پرمیژن Admin و اعمال پیکربندی XML. |
| **`setup_openssh.bat` / `.ps1`** | نصب خودکار سرویس OpenSSH روی ویندوز از طریق Winget، باز کردن پورت ۲۲ فایروال، تنظیم PowerShell به عنوان پیش‌فرض و تشخیص خودکار کلید عمومی SSH هاست لینوکس جهت ورود بدون پسورد. |
| **`refresh_shares.bat`** | پاکسازی کش اتصالات اشتراکی (SMB / Network Shares) و ری‌استارت سریع Windows Explorer جهت رفرش و نمایش آنی فایل‌های جدید بدون نیاز به ریبوت ماشین مجازی یا ویندوز. |

## ⚙️ سازگاری ویندوز و لینوکس (Cross-Platform)

- **انتهای خطوط (Line Endings):** کلیه فایل‌های اسکریپت ویندوزی (`.bat`, `.cmd`, `.ps1`) با تنظیمات `.gitattributes` ملزم به استفاده از فرمت **CRLF (`\r\n`)** هستند تا در ادیتورهای لینوکس (مانند Neovim یا VS Code) بدون آسیب به مفسر `cmd.exe` و `powershell.exe` ویرایش شوند.
- **یونیکد (UTF-8 with BOM / UTF-8):** اسکریپت‌های PowerShell برای سازگاری کامل با کنسول‌های پیش‌فرض ویندوز و جلوگیری از به هم ریختگی کاراکترها به صورت استاندارد ذخیره شده‌اند.
